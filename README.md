# README

This repository contains a pretty simple vibecoded app, which in essence forwards a call to the websites of ChatGPT, Perplexity, and Google Gemini, alongside other pinned apps of your choosing. 
The main reason why I made this is because of just how laggy the ChatGPT website is; the desktop version is always incredibly laggy, and the phone emulation in HTML > DevTools is kinda horrible. So, this program simulates a mobile user agent. Atleast in my tests, mobile UA's ChatGPT website is much better. I added Perplexity and Gemini (both Desktop UAs) for redundancy, since those are the free, no-login tools that I use most (other than GPT itself).

Currently, it is very badly made, but if you still wish to use it, then head on over to Releases/ and download the oldest package.
